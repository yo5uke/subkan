# SubKan

サブカンは、サブスクの料金・支払日・支払いカードをまとめて管理するアプリです。

Material Design 3 に沿った Android ネイティブアプリで、サービス名から自動でアイコンを取得し、
月々／年額のサブスクをすっきり一覧表示します。

---

## 📥 ダウンロード

最新版の APK は **[Releases ページ](../../releases/latest)** から入手できます。

> Android 端末向けの `.apk` ファイルです（iOS版はありません）。

### インストール手順（Android）

1. [Releases ページ](../../releases/latest) から `SubKan-vX.Y.Z.apk` をダウンロード
2. ダウンロードした APK ファイルをタップして開く
3. 初回は「**提供元不明のアプリ**」のインストール許可を求められるので、画面の案内に従って許可
   （設定 → アプリ → 不明なアプリのインストール、から許可できます）
4. インストール完了！

> **v2.0.0 をお使いになる方へ**
> v2.0.0 で Flutter から Android ネイティブへ全面的に書き換えたため、アプリ ID とデータの
> 保存形式が変わりました。v1.x からのデータは引き継がれず、別アプリとしてインストールされます。
> 詳細は [docs/migration-from-flutter.md](docs/migration-from-flutter.md) を参照してください。

## ✨ 主な機能

- **サブスク管理** — サービス名・金額・通貨（JPY / USD / EUR）・支払い間隔（月額 / 年額）・
  次回支払日・支払いカードを登録、編集、削除
- **金額が変わるものにも対応** — 光熱費のように毎月の金額が変動するものは、**件名だけ**でも、
  **概算の目安**を入れても登録できます。概算は `約 ¥4,000` のように表示され、「約」の表示は設定で
  切り替えられます
- **金額の表記を選択** — 記号（`¥1,480` / `$20`）と日本語（`1,480円` / `20ドル`）を切り替え可能
- **月額合計** — 年額プランは 12 で割って月額換算。複数通貨がある場合は `¥3,000 + $15` のように
  通貨ごとに並記します（為替換算はしません）。金額未入力のものは合計に含めません
- **カードごとの絞り込み** — 「すべて」＋カードごとのタブをスワイプで切り替え。合計金額は
  スワイプに追従してリアルタイムに変わります
- **アイコン自動取得** — サービス名から公式ロゴを自動表示。取得できない場合も、サービス名から
  一貫した配色のグラデーションタイルを自動生成
- **次回支払日の可視化** — 「あと◯日」「今日」を色付きでひと目で確認。支払日を過ぎたものは
  支払いサイクルから翌月・翌年へ自動的に繰り越して表示します
- **支払日の通知** — 前日の夜と当日の朝にお知らせ。前日・当日それぞれ ON/OFF と時刻を個別に設定
  できます（既定は前日 20:00・当日 8:00）。同じ日に複数の支払いがあっても通知は 1 通にまとまります
- **支払いカード管理** — 複数のカードを色分けし、各サブスクと紐付け。並べ替え・編集・削除に対応
  （削除は取り消し可能）
- **並び替え** — 登録日順 / 名称順 / 支払日順、昇順・降順に対応
- **ライト / ダークテーマ** — 端末設定に追従しつつ手動切り替えも可能
- **ダイナミックカラー** — Android 12 以降で壁紙由来の配色を利用（既定はオフ）
- **タブバーの配置** — 画面の上部／下部を選択可能
- **ローカル保存** — データは端末内にのみ保存。アカウント登録不要で、情報が外部サーバーに
  送られることはありません

## ⚠️ ご利用にあたって

- 個人開発の趣味プロジェクトです。動作の保証や継続的なサポートはありません。
- 配布している APK の署名について、インストール時に Google Play プロテクト等の警告が表示される
  場合がありますが、ご了承のうえ自己責任でご利用ください。
- アイコンの自動取得にはインターネット接続が必要です（取得できない場合は自動でカラータイルに
  なります）。取得の際、入力したサービス名（ドメイン）が画像取得サービス（Google および
  wsrv.nl）へ送信されます。

## 🛠️ 開発者向け

Kotlin + Jetpack Compose + Room の単一 Gradle モジュール構成です。

### 必要なもの

- JDK 17 以上（Android Studio 同梱の JBR で可）
- Android SDK（`compileSdk 37`）
- `local.properties` に `sdk.dir` を設定

### ビルド

```bash
./gradlew :app:compileDebugKotlin     # コンパイルのみ
./gradlew :app:testDebugUnitTest      # ユニットテスト
./gradlew :app:assembleDebug          # デバッグ APK
./gradlew :app:installDebug           # 実機へインストール
```

### リリース

`v2.0.0` のような**バージョンタグを push すると GitHub Actions が APK を自動ビルドして Releases に
添付**します（[ワークフロー](.github/workflows/release.yml)）。

```bash
git tag v2.0.0
git push origin v2.0.0
```

署名鍵はリポジトリに含めません。リリース署名はリポジトリ直下の `keystore.properties`
（gitignore 済み）から読み込み、無い場合は未署名 APK になります。CI では
`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD` の Secrets を使います。
